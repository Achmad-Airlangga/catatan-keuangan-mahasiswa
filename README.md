# DompetKampus — Catatan Keuangan Mahasiswa

Aplikasi web modern, simpel, dan responsif untuk membantu mahasiswa mencatat pemasukan dan pengeluaran harian, menghitung saldo, serta mengestimasi jatah belanja aman harian agar tidak kehabisan uang di akhir bulan.

## Fitur Utama
- **Ringkasan Saldo**: Total saldo, total pemasukan, dan total pengeluaran otomatis terhitung.
- **Jatah Belanja Aman / Hari**: Estimasi harian yang membantu mahasiswa mengontrol pengeluaran.
- **Kategori Mahasiswa**: Uang saku, beasiswa, kos, makan warteg, fotokopi buku kuliah, paket data, dan lainnya.
- **Quick Amount Chips**: Tombol cepat untuk nominal umum (`+10 rb`, `+20 rb`, `+50 rb`, dsb).
- **Filter & Pencarian**: Filter kategori transaksi, pencarian keterangan, dan pengurutan data.
- **Ekspor CSV**: Mengunduh seluruh catatan transaksi ke dalam format Excel/CSV.
- **Mode Gelap & Terang**: Tampilan modern dengan glassmorphism.
- **Penyimpanan Lokal**: Otomatis tersimpan di peramban menggunakan `localStorage`.

## Teknologi
- HTML5
- Vanilla CSS3
- Vanilla JavaScript (ES6+)

## Deploy ke Vercel
Aplikasi ini berbasis file statis murni sehingga dapat langsung di-deploy ke Vercel tanpa perlu build step apa pun.
